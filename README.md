# FlagStack GitHub Configuration

This repository contains shared GitHub configuration and community files for the [FlagStack organisation](https://github.com/flagstack).

Organisation-wide configuration may include:

- organisation profile content;
- contribution guidance;
- issue and pull-request templates;
- security policy defaults;
- community health files;
- shared GitHub configuration.

The public organisation profile is maintained in [`profile/README.md`](profile/README.md).
