# FlagStack GitHub Configuration

This repository contains shared GitHub configuration and community files for the [FlagStack organisation](https://github.com/flagstack).

## Organisation-wide files

The repository currently provides:

- [`CONTRIBUTING.md`](CONTRIBUTING.md) — contribution workflow, commit conventions and rebase-only history policy;
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — community behaviour standards;
- [`SECURITY.md`](SECURITY.md) — private vulnerability reporting guidance;
- [`SUPPORT.md`](SUPPORT.md) — support and issue-routing guidance;
- [`GOVERNANCE.md`](GOVERNANCE.md) — current maintainer-led governance model;
- [`CLA.md`](CLA.md) — Contributor Licence Agreement policy;
- [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) — default pull request checklist;
- `.github/ISSUE_TEMPLATE/` — default bug and feature request forms.

The public organisation profile is maintained in [`profile/README.md`](profile/README.md).

GitHub applies supported community health files from this public `.github` repository to organisation repositories that do not define their own override.
