# FlagStack Support

FlagStack is currently in early development. There is not yet a production support SLA or a stable release channel.

## Bugs

If you have found a reproducible bug, open a GitHub issue using the bug report template in the repository where the problem occurs.

Please include enough information for someone else to reproduce the behaviour, including relevant versions, environment details, expected behaviour, and actual behaviour.

## Feature requests

Use the feature request template to suggest a new capability or improvement.

For substantial architectural or API proposals, explain the problem being solved as well as the proposed solution. This makes it easier to consider alternatives before implementation begins.

## Questions

General support channels will be added as the project grows. Until then, use repository issues only when the question represents a concrete bug, documentation problem, or actionable feature request.

## Security

Do not use public issues for security vulnerabilities. Follow `SECURITY.md` for private reporting instructions.

## FlagStack Cloud

FlagStack Cloud is not yet generally available. Dedicated Cloud support channels and service expectations will be published before launch.
